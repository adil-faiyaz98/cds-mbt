## Community Support

### GitHub Issues

For bugs and feature requests: [GitHub Issues](https://github.com/adil-faiyaz98/cds-mbt/issues)

**Before opening an issue:**
1. Search existing issues for duplicates
2. Check [TROUBLESHOOTING.md](./TROUBLESHOOTING.md)
3. Gather version info: `npm ls cds-mbt && node --version`

**Good bug report includes:**
- cds-mbt version
- Node.js version
- @sap/cds version (if using CAP)
- Minimal code to reproduce
- Expected vs actual behavior
- Full error message/stack trace

### GitHub Discussions

For questions, ideas, and community help: [GitHub Discussions](https://github.com/adil-faiyaz98/cds-mbt/discussions)

Use Discussions for:

## Response Times

This is an open-source project maintained by volunteers. Expected response times:

| Issue Type | Target Response |
|------------|-----------------|
| Security vulnerability | 48 hours |
| Bug with reproduction | 1 week |
| Feature request | 2 weeks |
| General question | Best effort |

These are targets, not guarantees. Complex issues take longer.

## Staying Updated

### Release Notifications

Watch the GitHub repository for release notifications:
1. Go to [cds-mbt on GitHub](https://github.com/adil-faiyaz98/cds-mbt)
2. Click "Watch" → "Custom" → check "Releases"

### Changelog

See [CHANGELOG.md](./CHANGELOG.md) for version history.

### npm Updates

Check for updates:
```bash
npm outdated cds-mbt
```

Update to latest:
```bash
npm update cds-mbt
```
